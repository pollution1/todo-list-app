# 📋 待办事项清单应用

一个功能完整的待办事项应用，具有本地存储功能、数据导入导出和实时同步能力。

## ✨ 功能特性

### 核心功能
- ✅ **添加待办事项** - 快速添加新的任务
- ✅ **标记完成** - 点击复选框标记任务完成状态
- ✅ **删除事项** - 删除不需要的任务
- ✅ **本地存储** - 使用 LocalStorage 自动保存数据
- ✅ **智能过滤** - 查看所有、未完成或已完成的任务
- ✅ **统计信息** - 实时显示任务统计

### 高级功能
- 📤 **导出数据** - 将任务导出为 JSON 文件
- 📥 **导入数据** - 从 JSON 文件导入任务
- 🗑️ **批量清空** - 一键清空所有已完成的任务
- 📱 **响应式设计** - 完美适配各种屏幕尺寸
- 🎨 **现代 UI** - 漂亮的渐变设计和流畅动画

## 🚀 快速开始

### 方式 1：直接打开 HTML 文件

```bash
# 克隆仓库
git clone https://github.com/pollution1/todo-list-app.git
cd todo-list-app

# 用浏览器打开 index.html
open index.html
# 或在浏览器中打开：file:///path/to/index.html
```

### 方式 2：使用本地服务器

```bash
# 使用 Python 3
python -m http.server 8000

# 或使用 Node.js http-server
npx http-server

# 然后在浏览器中打开：http://localhost:8000
```

## 📚 使用指南

### 基本操作

1. **添加任务**
   - 在输入框输入任务内容
   - 按 Enter 或点击「添加」按钮

2. **标记完成**
   - 点击任务前面的复选框
   - 已完成的任务会显示删除线

3. **删除任务**
   - 点击任务右侧的「删除」按钮
   - 确认后任务被永久删除

4. **过滤任务**
   - 点击「全部」、「未完成」或「已完成」按钮
   - 列表会实时更新显示对应的任务

5. **清空已完成项**
   - 点击「清空已完成项」按钮
   - 系统会删除所有已完成的任务

### 数据导入导出

**导出数据**
```bash
# 点击「导出」按钮
# 系统会下载一个 JSON 文件：todos_2024-XX-XX.json
```

**导入数据**
```bash
# 点击「导入」按钮
# 选择一个之前导出的 JSON 文件
# 确认后数据会被导入（会覆盖现有数据）
```

## 📝 文件说明

### index.html
- 应用的 HTML 结构
- 定义了所有 UI 元素
- 加载 CSS 和 JavaScript 文件

### styles.css
- 完整的样式定义

- 动画和过渡效果

### storage.js

| 方法 | 说明 |
|------|------|
| `getTodos()` | 获取所有待办事项 |
| `saveTodos(todos)` | 保存待办事项 |
| `addTodo(text)` | 添加新事项 |
| `deleteTodo(id)` | 删除事项 |
| `toggleTodo(id)` | 切换完成状态 |
| `clearCompleted()` | 清空已完成项 |
| `exportToJSON()` | 导出为 JSON |
| `importFromJSON(file)` | 从 JSON 导入 |

| 方法 | 说明 |

## 💾 本地存储说明

### 存储方式
- 使用浏览器的 **LocalStorage API**
- 数据存储在浏览器本地，不需要服务器
- 关闭浏览器后数据仍然保存

### 存储格式
```javascript
// 存储结构
[
  {
    "id": 1234567890,
    "text": "完成项目报告",
    "completed": false,
    "createdAt": "2024-01-15T10:30:00.000Z"
  },
  // ...
]
```

### 存储限制
- 大多数浏览器限制为 **5-10MB**
- 可以存储几千个任务
- 清除浏览器数据会删除所有任务
